Here we visualized Maritime Piracy Heatmap and Temporal Analysis. Using geospatial data, we create a heatmap to highlight piracy hotspots and an animation to show how these locations have evolved over time.

1. Data sources: Maritime Piracy Incidents — from the National Geospatial-Intelligence Agency Maritime Safety Information Portal.(https://msi.nga.mil/).  
2. Land Polygons (10m Physical Vectors) — from  Natural Earth https://www.naturalearthdata.com/downloads/10m-physical-vectors/.
